# Voice request sample clips (ElevenLabs)

Generate one MP3 per locale in ElevenLabs (Speech Synthesis), then save here:

| File | Locale | Paste this exact script |
|------|--------|-------------------------|
| `request-az.mp3` | az | Nərimanovda 2 saatlıq it gəzdirən adam lazımdır. |
| `request-en.mp3` | en | I need someone in Narimanov for a 2-hour dog walk. |
| `request-ru.mp3` | ru | Нужен человек в Нариманове, чтобы погулять с собакой на 2 часа. |

Tips:
- Calm, clear adult voice; ~3–6 seconds; no music.
- Export **MP3** (or convert to MP3).
- Keep filenames exactly as above — the web “Nümunə səs” button loads `/audio/samples/request-{locale}.mp3`.
